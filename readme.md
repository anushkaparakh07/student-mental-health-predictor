# Student Mental Health Score Prediction

An end-to-end machine learning application that predicts student mental health scores based on social media usage and lifestyle factors.

## Technologies

- Python
- Scikit-learn
- Pandas
- NumPy
- FastAPI
- Pydantic
- Streamlit
- Joblib
- Plotly

## Features

- Machine learning based prediction
- Random Forest regression
- FastAPI REST API
- Pydantic input validation
- Streamlit web interface
- Real-time predictions
- Automated preprocessing pipeline

## Dataset

The project uses 5,000 student records with 13 features related to demographics, social media usage, academics and lifestyle.
